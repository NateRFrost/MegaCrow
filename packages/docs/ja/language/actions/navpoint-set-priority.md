# navpoint_set_priority


<AvailabilityCard reach="yes" />

## 説明

ナビポイントの描画優先度（`high`、`normal`、`low`、`blink`）を設定します。

<ActionParameters />

## 例

```megalo
action navpoint_set_priority hill high
```

HREK の `broken/calvinball.txt` からの例。
