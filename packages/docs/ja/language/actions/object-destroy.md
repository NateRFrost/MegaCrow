# object_destroy


<AvailabilityCard reach="yes" />

## 説明

オブジェクトを即座に破壊します（エンジン上の扱いは `delete_object` とは異なります）。

<ActionParameters />

## 例

```megalo
action object_destroy ball
```

HREK の `broken/hot_potato.txt` からの例。
