# random

<AvailabilityCard reach="yes" />

## 説明

設定された最小値と最大値の間の乱数整数を出力変数に書き込みます。最小値は**含む**、最大値は**含まない**です（例: `action random 0 5 x` は 0–4 を返します）。

<ActionParameters />

## 例

```megalo
action random 0 5 randumb
```

HREK の `broken/derekball.txt` からの例。
