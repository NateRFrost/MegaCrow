# timer_set_rate


<AvailabilityCard reach="yes" />

## 説明

タイマーのティックレートを設定します。`0` は一時停止、`-1` はカウントダウン、`1` は通常速度です。

<ActionParameters />

## 例

```megalo
action timer_set_rate period_timer 1
```

HREK の `broken/1Flag_Boneyard_Extreme.txt` より。
