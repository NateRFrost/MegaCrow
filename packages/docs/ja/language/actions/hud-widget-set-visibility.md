# hud_widget_set_visibility


<AvailabilityCard reach="yes" />

## 説明

プレイヤー参照に対して HUD ウィジェットの表示／非表示を切り替えます。

<ActionParameters />

## 例

```megalo
action hud_widget_set_visibility obj_bfg current_player true
```

HREK の `broken/kim-1flag-hill.txt` からの例。
