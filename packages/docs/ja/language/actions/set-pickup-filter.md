# set_pickup_filter


<AvailabilityCard reach="yes" />

## 説明

オブジェクトを拾える対象を制限します（`all`、`allies`、`enemies`、`no_one`）。

<ActionParameters />

## 例

```megalo
action set_pickup_filter flag enemies
```

HREK の `broken/calvinball.txt` より。
