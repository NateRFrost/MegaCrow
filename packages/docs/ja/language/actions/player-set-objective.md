# player_set_objective


<AvailabilityCard reach="yes" />

## 説明

[動的文字列](/ja/language/enums/dynamic-strings) を使って、プレイヤーに表示するオブジェクティブテキストを設定します。

<ActionParameters />

## 例

```megalo
action player_set_objective current_player "+%n" 1
```

HREK の `broken/calvinball.txt` からの例。
