# set_fireteam_respawn_filter


<AvailabilityCard reach="yes" />

## 説明

オブジェクト上のファイアチーム再スポーン権限を制限します。

<ActionParameters />

## 例

```megalo
action set_fireteam_respawn_filter respawner 0
```

HREK の `broken/1Flag_Boneyard_Extreme2.txt` より。
