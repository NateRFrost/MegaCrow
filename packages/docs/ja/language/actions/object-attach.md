# object_attach


<AvailabilityCard reach="yes" />

## 説明

オフセットと制約パラメータを指定して、あるオブジェクトを別のオブジェクトにアタッチします。

<ActionParameters />

## 例

```megalo
action object_attach the_flag current_team.goal 0 0 0.15
```

HREK の `broken/1Flag_Boneyard.txt` からの例。
