# Forced Change Color Setting

[プレイヤートレイト](/ja/language/enums/player-traits) enum の `color` フィールド用の値構文です。プレイヤーのアーマーティントをプリセット色に強制します。

ManagedMegalo は名前付きトークンを `e_forced_change_color_setting`（`forced_change_color_names`、14 エントリ）に対応付けます。

## 名前付き値

| 値 | 効果 |
|----|------|
| `off` | 強制色なし |
| `red` | 赤ティント |
| `blue` | 青ティント |
| `green` | 緑ティント |
| `yellow` | 黄ティント |
| `purple` | 紫ティント |
| `orange` | オレンジティント |
| `brown` | 茶ティント |
| `pink` | ピンクティント |
| `white` | 白ティント |
| `black` | 黒ティント |
| `zombie` | Infection ゾンビティント |
| `extra4` | 追加パレットスロット 4 |
