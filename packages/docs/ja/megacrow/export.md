# エクスポート

ツールバーの **Export** で、現在の Megalo ゲームタイプをコンパイルし、選択したバイナリ形式で保存します。**Export as** メニューから形式を選びます。

どの形式も同じコンパイル済みバリアントから生成され、コンテナと想定用途だけが異なります。

## 形式

### `.mglo`

**向いている用途:** ホットリロードおよび HREK / MCC の `maps/megalo` ワークフロー。

- 最小のカスタムバリアントペイロード（生の Megalo ビットストリーム）
- デバッグ／開発者向けリロード用に、ワークスペースの **output folder**（通常は `maps/megalo`）へ配置
- バリアントを完全な BLF ドキュメントでは包まない

スクリプトを反復し、ゲームの megalo maps ディレクトリから読み込むときに使います。

### `gvar`

**向いている用途:** Xbox 360 のマッチメイキング／デバッグ用ネットコマンド。

- Xbox 360 のマッチメイキング風ロード向けの BLF ラッパー
- デバッグビルドでは `net_load_and_use_game_variant` で読み込み
- BLF フレーミングのため `.mglo` より大きい

File Share や MCC のセーブ形式ではなく、360 マッチメイキングの BLF パスが必要なときに `gvar` を選んでください。

### `mpvr`

**向いている用途:** 通常のゲーム内セーブ、File Share、Xbox／PC のゲームタイプファイル。

- Reach カスタムバリアント向けの標準 BLF パッケージ
- ゲーム内保存、File Share へのアップロード、Xbox／PC 間での共有に適する
- 一般的にやり取りされる「フル」なゲームタイプファイル

生の `.mglo` ビットストリームではなく、通常の共有／読み込み可能なゲームタイプファイルが欲しいときは `mpvr` を選んでください。

### Autosave Queue（`asq`）

**向いている用途:** オートセーブキュー経由で **Recent Games** に表示する。

- 単体のバリアント置き換えではなく、Autosave Queue ファイルを書き出す
- ゲームがオートセーブキュー用に期待する場所に置けば、ゲームタイプが Recent Games に現れる
- File Share や、毎回の `maps/megalo` 手動コピーを経ずにテストするのに便利

## 形式の選び方

| 目的 | 形式 |
|------|------|
| `maps/megalo` での最速イテレーション | `.mglo` |
| 360 デバッグの `net_load_and_use_game_variant` | `gvar` |
| File Share／通常セーブ／クロスプラットフォーム | `mpvr` |
| オートセーブキュー経由の Recent Games | Autosave Queue |

エクスポート時のコンパイルには、現在の [設定](/ja/megacrow/settings)（作者名、コンパイラプロファイル、厳密コンパイラ）が使われます。
